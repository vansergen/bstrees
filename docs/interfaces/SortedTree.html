    Interface SortedTree<T>Abstract

    A sorted collection of unique values, ordered by a Comparator. BSTree and AVLTree share this API; use this type to accept either of them.

    Values are unique with respect to the comparator: inserting a value equal to a stored one keeps the stored one. Iteration yields values in ascending order.

    Every method that takes a value passes it to the comparator, even when the tree is empty, so a value the comparator rejects (such as NaN with the default comparator) throws whether the tree is empty or not.

      book.getOrInsert({ price: 10, orders: [] }).orders.push(2);

    range

    • range(options?: RangeOptions<T>): TreeIterator<T>

      Iterates over the values within the bounds, in ascending order unless reverse is set.

      Parameters

      • Optionaloptions: RangeOptions<T>

      Returns TreeIterator<T>

      Example

      const tree = AVLTree.from([1, 2, 3, 4, 5]);
      [...tree.range({ gte: 2, lt: 4 })]; // [2, 3]
      [...tree.range({ gt: 3, reverse: true })]; // [5, 4]

      Throws

      If both gt and gte (or lt and lte) are set, or if the comparator rejects a bound. Bounds are checked when range is called, not when the iteration starts.
